# AuditFlow V3 — 離線審計案件管理系統

## V3 新增功能
### 案件關聯視覺化
以「問題」為核心，顯示：
問題 → 根本原因 → 查核程序 → 證據 → 查核發現

### 附件資料
可將小型附件儲存在目前瀏覽器的本機資料中，並關聯至：
- 問題
- 證據
- 查核程序

### 大事記時間軸檢視
「大事記」頁面新增「列表／時間軸」切換，時間軸模式會以圖形化橫向節點呈現所有事件（依重要性標色），點選節點可在下方看到完整內容、編輯或刪除。

### 查核計畫大事記（獨立頁籤）
新增「查核計畫大事記」頁籤，用來記錄「受查標的執行的計畫／專案」本身的時間軸，而不是查核團隊自己的工作紀錄。每筆記錄包含：計畫／項目名稱（可從先前輸入過的名稱自動帶出）、時間點、辦理內容、預定期限（選填）、時效狀態（準時／逾期／待觀察／不適用，手動選擇）、發現問題／備註。可依計畫名稱篩選，方便同一案件同時追蹤多個計畫。

## AI 分析（選用功能，需自備 Gemini API 金鑰）
在「AI 分析」頁面貼上自己的 Google Gemini API 金鑰即可使用。這是 BYOK（Bring Your Own Key）設計：
- 金鑰只會存在使用者自己瀏覽器的 LocalStorage，不會寫入原始碼、不會上傳到任何伺服器。
- 按下「產生 AI 分析」時，瀏覽器會直接呼叫 Google Gemini API，把該筆問題資料送出去做分析；不使用此功能時，整個工具維持完全離線。
- 若 Google Cloud 專案已啟用計費且預付額度有餘額，Google 官方條款承諾不會用這些內容訓練模型；若使用免費額度金鑰，內容可能被用於改善 Google 產品，請避免用免費額度送出機敏案件資料。
- 若出現「HTTP 429／prepayment credits are depleted」錯誤，代表 Google 帳戶的預付額度用完了，需到 https://aistudio.google.com/billing 加值，跟金鑰本身是否正確無關。
- 目前串接的模型名稱寫在 `app.js` 的 `GEMINI_MODEL` 常數，若 Google 未來調整模型代號，更新這裡即可。
- 「AI 分析結果」下方新增「🗨 向 AI 追問」對話框：可以先按「產生 AI 分析」再針對報告內容繼續追問，也可以不按分析、直接輸入問題（第一則訊息會自動帶入目前選擇的問題資料）。對話會透過 Gemini 的 `previous_interaction_id` 機制串接上下文，不需要每次都重新傳送完整資料。切換選擇的問題、切換案件，或按「清空對話」都會重置這個對話串。
- 每一則 AI 回答下方都有三個快速按鈕，可以把這段回答內容直接運用，不用手動複製貼上：
  - 📥 填入根本原因：直接寫入目前選擇問題的「根本原因」欄位（若原本已有內容，會用「【AI 建議】」標記附加在後面，不會覆蓋掉舊資料）。
  - 📥 新增為查核程序：開啟「新增查核程序」視窗，自動帶入標題與查核程序內容並關聯到目前問題，存檔前仍可自行修改。
  - 📥 新增為查核發現：開啟「新增查核發現」視窗，自動帶入問題描述與改善建議並關聯到目前問題，存檔前仍可自行修改。
  （因為新增了「關聯問題」欄位，「查核發現」的新增／編輯視窗現在也能選擇要連結的問題，查核發現列表也會顯示所屬問題。）

## 側邊導覽列
側邊選單項目變多後，超出視窗高度時會自動出現卷軸（`overflow-y:auto`），直接在側邊欄裡往下捲動即可看到所有頁籤，不需要縮小瀏覽器畫面。

## 匯出／匯入專案備份
因為所有資料都只存在瀏覽器的 LocalStorage 裡，一旦使用者清除瀏覽器的 Cookie、快取或網站資料，畫面就會直接回到最原始的空白狀態，之前輸入的內容、設定和暫存的 Gemini API 金鑰都會一併消失，且無法復原。「備份與還原」頁面的匯出／匯入功能因此升級為「專案備份」，一次涵蓋：
- 所有案件、大事記、查核計畫大事記、問題分析、查核程序、證據、查核發現、附件。
- （可選）已儲存的 Gemini API 金鑰——匯出時預設會勾選一起匯出，還原時會自動填回「AI 分析」頁面，不用重新貼一次。

因為勾選匯出金鑰後，備份檔會包含明碼的 API 金鑰，頁面上會顯示提醒：請把備份檔存放在安全的地方，要分享備份給別人之前記得先取消勾選再重新匯出一次。建議定期匯出備份存到自己的電腦或雲端硬碟，且在清除瀏覽器資料、換瀏覽器或換裝置之前，一定要先匯出一份，才能之後用「匯入備份」完整還原。

## 重要限制
本版本為純前端、完全離線設計，附件使用瀏覽器 LocalStorage 儲存，因此容量有限且依瀏覽器而異。
建議單一附件控制在 2MB 以下，並定期使用 JSON 匯出備份。

注意：附件會被編碼寫入 JSON 備份，因此包含附件的備份檔可能較大。

## GitHub Pages
只需上傳：
- index.html
- style.css
- app.js

案件資料及附件不會自動提交到 GitHub Repository，而是保留在使用者的瀏覽器本機。

## 建議
對真正敏感或大型審計文件，建議後續升級為 IndexedDB 版本或企業內部伺服器版本，以獲得更大的儲存空間與更完整的權限管理。
