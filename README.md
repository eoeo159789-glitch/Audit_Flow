# AuditFlow V2 — 離線智慧審計工作底稿系統

## V2 新功能
- 5 Why 根本原因分析
- 魚骨分析（人員、制度、流程、法規、預算、資料、管理、其他）
- 證據編號與問題關聯
- 查核程序管理與執行狀態
- 問題 × 程序 × 證據自動彙整
- 審計工作底稿頁面
- 瀏覽器列印／另存 PDF
- JSON 完整備份與還原
- 完全 LocalStorage 離線儲存

## GitHub Pages
將 index.html、style.css、app.js 上傳至 Repository 根目錄，再至 Settings → Pages 啟用 main branch / root。

## 安全提醒
GitHub Pages 僅提供網站程式。案件資料預設存在瀏覽器 LocalStorage。
不要將實際敏感案件 JSON 或附件提交至公開 Repository。
