Gemini API 金鑰設定

🔒 金鑰只會存在「這個瀏覽器」的本機儲存空間，不會上傳到任何伺服器；按下「產生 AI 分析」時，會由你的瀏覽器直接連線到 Google Gemini API 送出資料。若你的 Google Cloud 專案已啟用計費（預付額度有餘額），Google 官方承諾不會使用這些內容訓練模型；若使用免費額度的金鑰，內容有可能被用於改善 Google 產品，請避免在免費額度上送出機敏案件資料。

備份與還原

資料不會上傳，只存在這個瀏覽器裡——一旦清除瀏覽器的 Cookie／快取／網站資料，所有內容就會消失。請定期將專案匯出為 JSON 備份檔，保存在你自己的電腦或雲端硬碟，需要時可以完整還原。

⬇ 匯出專案備份

將所有案件、大事記、查核計畫大事記、問題、查核程序、證據、查核發現與附件下載為 JSON。

⚠️ 勾選上面的選項後，匯出的 JSON 檔會包含你的 API 金鑰明碼，請將備份檔存放在安全的地方，不要隨意分享給他人；若要把備份給別人看，匯出前請先取消勾選。

⬆ 匯入備份

從先前匯出的 JSON 還原資料；如果備份檔裡有包含 API 金鑰，也會一併還原。匯入後會覆蓋目前的專案內容。
